# SYNAPSE

SYNAPSE is an explainable AI water-pump monitoring and decision-support system.

The project is being built sequentially from the master plan. It is advisory only: it will recommend, explain, compare, and simulate, but it will not autonomously control real hardware.

## Development

Create a Python 3.11+ environment and install development dependencies:

```text
python -m pip install -e ".[dev]"
```

Run the current test suite:

```text
python -m pytest
```

The current implementation status is maintained in [docs/SYNAPSE_PROJECT_STATUS.md](docs/SYNAPSE_PROJECT_STATUS.md).
